# 🛍️ NovaCart

A modern and responsive **E-Commerce Website** built using **HTML, CSS, and JavaScript**.

NovaCart allows users to browse products, search for items, filter products by categories, view product details, manage their shopping cart, and switch between Light and Dark modes.

---
## 🌐 Live Demo

🚀 **Try NovaCart here:**

👉 [NovaCart | Discover Amazing Products](https://lalit-0052.github.io/NovaCart/)

---

## ✨ Features

- 🛍️ Browse products from DummyJSON API
- 🔍 Search products by name, brand, or category
- 📱 Filter products by categories
- 📦 View detailed product information
- 🖼️ Product image gallery
- 🛒 Add products to cart
- ➕ Increase product quantity
- ➖ Decrease product quantity
- ❌ Remove products from cart
- 🗑️ Clear the entire cart
- 💰 Automatic price calculation
- 🏷️ Discount calculation
- 🚚 Free shipping logic
- 🧾 Tax calculation
- 🌙 Dark Mode
- ☀️ Light Mode
- 💾 Cart data saved using LocalStorage
- 📱 Fully responsive design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DummyJSON API
- LocalStorage
